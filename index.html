📖 Guia de Fórmulas e Notações Aceitas

Você pode combinar qualquer uma dessas notações diretamente no campo de fórmula ou nos seus botões customizados:

Sintaxe Descrição Exemplo
XdY Rola X dados de Y faces poliédricas 3d6, 1d20, 1d100
khN Mantém os N maiores dados (Keep Highest) 2d20kh1 (Vantagem no D&D 5e)
klN Mantém os N menores dados (Keep Lowest) 2d20kl1 (Desvantagem no D&D 5e)
dlN Descarta os N menores dados (Drop Lowest) 4d6dl1 (Atributos de D&D)
dhN Descarta os N maiores dados (Drop Highest) 4d6dh1
! Dado Explosivo (rola outro dado se tirar o valor máximo da face) 3d6!
>=N ou >N Contagem de sucessos para sistemas Storyteller / WoD / Vampire 6d10>=6
dF Dados FATE / Fudge (-1, 0, +1) 4dF + 2
+, -, *, / Operações matemáticas aritméticas e bônus fixos 1d20 + 7, 2d6 * 2
# Motivo Adiciona um rótulo explicativo que é registrado no histórico 1d20 + 5 # Ataque Adaga
